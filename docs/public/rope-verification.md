# RoPE教材の導入と検証

2026-10-10

## 配置

- `/learn/position/`：64ペア、1 head全体の内積、相対位置、スケール・maskへの接続を補足。
- `/learn/attention/`：スコアに使うQ/KはRoPE適用後であることを補足。
- `/labs/rope/`：説明用の7位置で回転と内積を選んで比較する専用実験。実験一覧・左ナビ・検索索引にも登録。
- 全体地図のQ/K RoPE、位置係数、Attention scoresの補足から実験へリンク。地図の配置は維持。

## 意味と仮定

モデル実測ではない仮定値。提供された7個ずつのQ/K整数値をそのまま使用。Q/K Norm後・RoPE直前の値とみなす。128次元中の0,1,64,65だけに値があり、他124成分は0。Q head 0と対応するK head 0で説明する。

Qwen3の参照実装のペアは前半・後半で対応する (i,i+64)。回転は全64ペアに適用され、内積は1 headの128成分全体で1個。4成分の図は値がある部分の抜粋で、別の4次元モデルではない。

Sはスケーリング前の内積。AttentionスコアはS/√128。未来位置はt>pでmaskされる。未来の式を表示する操作は、実際のAttentionからmaskを外す操作ではない。softmaxやVの加重和は既存Attention Labへつなぐ。

ωは記号のまま表示。内積の係数はデータから生成。RₚᵀRₜ=Rₜ₋ₚは列ベクトル表記での同値変形で、追加の回転処理を行う図ではない。

## UI

既存の色・枠・ナビを使用。通常は位置差と参照可否の7×7表。任意で各マスに内積式を表示する。選択したQ/Kの回転行列・回転結果・相対位置の導出・最終式を下に表示。代入の詳細は開閉可能。標準MathMLで行列・添字・転置・分数を組版し、狭幅では数式と表をキーボードでも横に読める。最終式は縦に分けて表示。

既存のUI知見（全体の関係と詳細の分離、必要な情報の粒度、狭幅と実表示の確認）を適用。新しい一般ルールとしてのスキル更新は不要と判断。Reactの確認では状態の範囲、数式生成の純粋関数への分離、固定データのみからのMathML生成、ネイティブbutton/checkbox/tableの意味を確認。

## 検証

- Q0×K0=20、Q3×K1の係数=[14,23,-1,18]。
- 全49組・2種類の回転速度で、独立した128次元回転計算と相対位置の係数式が一致。
- Q/Kの両位置へ同じオフセットを加えても内積が一致。対角では元の内積に一致。
- 参照可能28組、未来21組。未来選択後に非表示へ戻すと有効な同じ行の対角へ選択を戻す。
- 型検査（診断なし）、単体27件、既存ブラウザー17件、新教材の操作・キーボード2件、194ページの静的リンク検査が成功。
- 1440/768/390/320pxでページの横はみ出しなし。MathML領域内の横スクロールは意図した動作。
- PC/スマートフォン、明暗、全式表示、回転行列と最終式を画像で目視確認。アクセシビリティ自動検査も成功。
- JavaScriptなしでも初期選択の説明と式は読める。操作にはJavaScriptが必要。

数式の一致は説明例の検証で、学習済みモデルのQ/K値を実測した検証ではない。全ブラウザー・全支援技術の実機検証は未実施。

## 計算一覧の追加検証（2026-10-10）

- 「概要＋下の計算」と「計算一覧」を切り替え可能。選択したQ/Kと未来位置の設定を共有する。
- 計算一覧にはQ/Kの回転14件、参照可能な内積28件を展開。未来位置の表示時は全49件の導出を表示する。
- 各交点は内積の同値変形、数値代入、行列とKの積、4成分の寄与、最終式を表示。表全体のみを縦横にスクロールする。
- 短いQ/K見出しを固定し、回転・選択した交点への移動、表示幅の拡大に対応。狭い画面でも数式は縮小せず横に読む。
- 型検査、数式の単体27件、教材のブラウザー3件、194ページの静的リンク検査を実施。全49件の数式がセルからはみ出さないこと、切り替え時の選択維持、キーボードスクロール、アクセシビリティを確認した。
- 表の先頭・途中式・最終式・スマートフォン表示を目視確認。320/390/768pxでページ全体の横はみ出しなし。
- UI知見の「必要な粒度と全件列挙を区別する」を適用。今回は各組の固有の計算を比較する目的なので全件表示を選べるようにした。既存知見の適用範囲内であり、一般ルールの追加は不要と判断した。
