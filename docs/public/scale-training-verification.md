# scaleの学習教材の検証

確認日：2026-11-21

## 資料の取得範囲と採用判断

会話取得ツールで末尾の整理を読み、ログイン済みEdgeのアクセシビリティ情報とスクロール操作で過去の本文へ遡った。自作MLPの最大絶対差0.0・allclose=Trueという既存教材との重複まで確認した。固定scale=0.5の実測、Moduleとforwardの区別、学習の実測30 Step、参照とコピー、Loss・勾配・Optimizerの疑問、および末尾の更新版整理を照合した。全過去会話の完全なエクスポートではない。会話内のNotionへの保存依頼は今回の操作指示として実行していない。

既存のmodel-editingにはModuleとモデルクラス・インスタンスの関係を補い、固定倍率から学習までをscale-trainingという独立した教材にした。コード検索にはscale-mlp・compare-scale・train-scaleを追加した。コード本文はJSONを正本として教材へ読み込み、詳細画面に準備と行ごとの説明を付ける。

## 実モデルの検証

`verification/verify_scale_training.py`が公開する3レシピを直接読み込んで実行する。モデルのダウンロードは行わず、既存キャッシュを使用する。

- Qwen/Qwen3-0.6B、revision `c1899de289a04d12100db370d81485cdf75e47ca`
- PyTorch 2.14.1+cu130、Transformers 5.20.2、CUDA、bfloat16
- 入力「雨が降る仕組みを説明してください」、thinking無効のchat template、24 Token
- 固定scale=0.5：logits最大絶対差5.265625、平均絶対差1.5314819812774658。通常・改造の次Token IDはいずれも100029
- Adam、lr=0.05、30更新：最終scale 0.394052118062973
- 最後の更新前Loss 0.08180169016122818。更新後に再計算したLoss 0.07870113104581833

Parameterの登録・shape・dtype・device、固定scaleがstate_dictに入らないこと、元のLinear共有、倍率0・0.5・1、出力dtype、勾配の存在、Teacherに勾配がないことを検査した。元のParameterの参照・更新version・勾配設定を照合し、正常終了時とStudentのForwardへ例外を注入した場合の復元を確認した。小さいSGDの更新例と勾配蓄積4→8も確認した。

提供ログの固定倍率比較と学習結果を再現したが、生成文章の再実行・別入力での品質評価はこの検証には含めない。学習の収束や一般化の証拠として扱わない。
