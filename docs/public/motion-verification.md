# 動きで学ぶ：実装・確認記録

## 構成

上部の「動きで学ぶ」から6章・26段階をたどる。既存の一覧地図、教材、実験室から該当段階へ移動できる。地図から移動した場合は元の地点へ戻れる。

- 入力：文章、トークン分割、ID、Embedding
- 行列：転置、行列積、RMSNorm
- Attention：Q/K/V、Head、RoPE、スコア、Mask、Softmax、Vの加重和、Head連結
- MLP：Residual①、gate/up、SiLU、要素積、downとResidual②
- 層：28層の前後比較、Final RMSNorm、LM head
- 生成：Greedy/Sampling、IDの追加、各層のKV Cache

## 数値の扱い

固定revisionのQwen3-0.6B、paddingなしの7トークンを例とする。Tokenizer・Embedding・各層の先頭位置8成分は、既存の検証fixtureから必要分を転記した。出典条件は画面末尾にも表示する。

- モデルrevision：c1899de289a04d12100db370d81485cdf75e47ca
- Transformers：5.18.0、CPU、BF16
- 元データ：tests/fixtures/qwen-embedding-reference.json、qwen-hidden-states-reference.json
- hidden_states[28]はFinal RMSNorm後。Layer 27直後は別のraw値を使用する。
- 全ベクトル・行列の数値をブラウザで実行する機能ではない。実測値の前後比較と、小さな計算例を区別する。
- 転置は各要素を[i,j]から[j,i]へ移動する。RoPEの回転と表現を分ける。
- 行列積は行と列の組と、成分積・和を同期表示する。
- KV Cacheでは各層のK/Vと、新しい位置の追加を描く。ID選択だけではcacheが増えないことを明記する。

## 操作と配慮

連続再生、一段階の再生、一時停止、速度変更、位置スライダー、段階の直接選択を提供する。背景タブでは停止し、OSの動き軽減設定では結果を静止表示する。描画領域を選択しているときのみ左右キーで段階、Spaceで再生を操作できる。各層の実測値は層番号でも選べる。

Q/K/Vとgate/upは上下の独立した領域で並列性を表現する。数値は小数3桁を基本とし、省略範囲を明記する。狭幅では図の内部を横スクロールでき、ページ全体をはみ出させない。

## 確認

全26段階の図、計算式、コード、関連教材へのリンク、URLによる段階復元を自動確認する。再生・停止・移動・スクラブ・動き軽減、地図との往復、外部の戻り先を受け入れないことも確認する。

各段階の完了画面と、代表場面の開始・途中・完了を画像で目視する。Embeddingの行間、数値のセル内余白、層比較図の上下間隔を修正した。明暗テーマと390px幅も確認する。確認画像は公開対象外の.cacheに保存する。
