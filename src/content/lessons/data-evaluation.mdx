## 三つの役割

| 分割 | 用途 |
|---|---|
| train | 重みを更新する |
| validation | 設定や学習の停止を選ぶ |
| test | 最後に未使用条件で比較する |

ランダムに行を分けるだけでは、同じ文書の似た部分が複数の分割に混ざる場合があります。文書・利用者・時間など、データの由来に合った単位で分けます。

## 損失とperplexity

平均の次トークン負の対数尤度に自然指数を適用したものがperplexityです。低いほど正解列へ高い確率を割り当てたことを示しますが、Tokenizerや評価の切り方が違う値をそのまま比較できません。

```python
import math
mean_nll = 1.5
print(round(math.exp(mean_nll), 3))
```

```text
4.482
```

これは指標の計算例で、実モデルの評価結果ではありません。

## 過学習の兆候

train lossが下がり続けても、validation lossが悪化する場合があります。訓練データを覚えることと、未見の入力へ適用できることは別です。少数の生成例がよく見えたことだけで改善と結論づけません。

## 記録する評価条件

データの版と分割、Tokenizerのrevision、会話テンプレート、最大長、切り詰め方法、seed、生成設定、評価コードを残します。何を正解とするかも明文化します。

## 改造に使える小さな評価セット

まず目的に合う十数件の固定入力と判定基準を用意し、回帰を早く見つけます。その後、目的に合った広い評価へ進みます。小さなセットの成功率を一般的な能力の測定だと扱わないことが重要です。
