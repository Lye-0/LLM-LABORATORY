## 内積は対応する要素を掛けて足す

```python
import torch
x = torch.tensor([1., 2.])
w = torch.tensor([0.5, -1.])
print(torch.dot(x, w))
```

```text
tensor(-1.5000)
```

1×0.5 + 2×(−1) = −1.5です。Embeddingが行を「選ぶ」のに対し、内積では値を掛け合わせます。

## 行列積のshape

`[M,K] @ [K,N] → [M,N]`。内側のKが一致する必要があります。行列積と要素ごとの積は違います。PyTorchでは`@`が行列積、`*`が要素ごとの積です。

```python
x = torch.tensor([[1., 2.]])
weight = torch.tensor([[1., 0.], [0.5, -1.]])
y = x @ weight.T
print(y)
print(y.shape)
```

```text
tensor([[ 1.0000, -1.5000]])
torch.Size([1, 2])
```

## 行列積・要素積・加算を区別する

同じ二つのTensorでも、演算によって結果は変わります。

```python
a = torch.tensor([[1, 2], [3, 4]])
b = torch.tensor([[5, 6], [7, 8]])
print(a @ b)  # [[19, 22], [43, 50]]：行と列の内積
print(a * b)  # [[5, 12], [21, 32]]：対応する場所同士の積
print(a + b)  # [[6, 8], [10, 12]]：対応する場所同士の和
```

| 演算 | Decoder Layerでの例 | どこを組み合わせる？ |
|---|---|---|
| 行列積 `@` / matmul | Linearの`x @ weight.T` | 入力成分を掛けて足し、出力成分を作る |
| 要素積 `*` | MLPの`SiLU(gate) * up` | 同じ位置・同じ成分同士を掛ける |
| 加算 `+` | Residual connection | 同じ位置・同じ成分同士を足す |

例えば二つの`[7,3072]`は要素積なら計算できますが、そのまま行列積にすると内側の3072と7が合いません。名前に「掛ける」とあっても、演算子とshapeをセットで確認します。

## Linearは末尾の軸を変換する

```python
from torch import nn
layer = nn.Linear(2, 3)
inputs = torch.zeros(1, 4, 2)
print(layer.weight.shape)
print(layer(inputs).shape)
```

```text
torch.Size([3, 2])
torch.Size([1, 4, 3])
```

batchとsequenceの位置は保ち、各位置の2成分を3成分へ変換します。出力は`x @ weight.T + bias`です。出力の数値は初期乱数で変わるので、ここではshapeを観察します。

## broadcastは軸を合わせて計算する規則

biasが`[3]`でも、`[1,4,3]`の各位置へ加えられます。これはbroadcastによるものです。小さいTensorを実際に何度もコピーするという意味とは限りません。末尾から、同じ長さか長さ1の軸であるかを確認します。

## projは変換を行う層の名前

`proj`はProjectionの略です。ここでは学習済みLinearによる変換を意味し、数学の直交射影とは限りません。`q_proj`は処理する部品、`q = q_proj(x)`の`q`はその出力Tensorです。

| Qwen3-0.6Bの部品 | 入力 → 出力の成分数 | 保存されたweightのshape |
|---|---|---|
| q_proj | 1024 → 2048 | `[2048,1024]` |
| k_proj / v_proj | 1024 → 1024 | 各`[1024,1024]`（別々の重み） |
| o_proj | 2048 → 1024 | `[1024,2048]` |

これらはbiasなしです。Q/K/Vの入力は共通の正規化後Hidden State、o_projの入力はHead出力を連結したものです。`[7,2048] @ weight.T [2048,1024] → [7,1024]`のように、保存shapeと実際に右から掛ける向きを分けます。

## 重みと活性値を分ける

重みは学習で更新するパラメータです。活性値は入力を処理して得る中間結果です。両方Tensorですが、役割・寿命・保存の必要性が違います。この区別はメモリ量や量子化を考える基礎になります。
